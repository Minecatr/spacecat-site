## Overview
Opsotx is an experimental shooter game to test capabilities of multiplayer.

### Controls
Movement/Driving - WASD
Jump - Space
Sprint - Shift
Shoot - LMB
Aim/Destroy - RMB
Menu - Escape
Reload - R
Modify/Select - Q
Interact - F

### Notes
This game was created using the Godot engine.
You can find the gun models used in the game [here](https://sketchfab.com/Lolik123654).
