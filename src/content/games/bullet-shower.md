# Overview
Bullet shower is a Rhythm/Bullet hell type game similar to just shapes and beats.

# Controls
Move - WASD | MOUSE | JOYSTICK
Teleport - SHIFT | RMB | DPAD | ARROW KEYS

# Notes
This game was created using the Godot engine. the music can be found [here](https://www.youtube.com/playlist?list=PLQfJCrsbsw0-GIwrqPOulUdqu0m4ySG4S).
